## Первый администратор

В конфигурации запуска backend:
- `DB_PASSWORD` — прежний пароль PostgreSQL;
- `ADMIN_USERNAME` — логин первого администратора: 3–64 строчных латинских букв, цифры, дефис или подчёркивание;
- `ADMIN_PASSWORD` — пароль администратора: минимум 8 символов, максимум 72 байта UTF-8.

После первого успешного запуска можно убрать **обе** переменные ADMIN_USERNAME и ADMIN_PASSWORD.
Пароль сохраняется в БД в виде BCrypt-хеша. Повторный запуск не меняет пароль существующего администратора.
Регистрация создаёт обычных пользователей. Администратор создаёт ресурсы и назначает управляющих.
Старые брони принадлежат отключённому legacy-system; административная отмена чужой брони требует причину.

Проверки frontend не изменяли рабочую схему public. Обычный запуск приложения применяет миграции к выбранной рабочей схеме.
Для будущей реальной интеграции Google Calendar потребуются настройки OAuth приложения владельца.
