# Минимальный frontend Reservation
Цель: вручную пользоваться существующим Java API из браузера.
Путь: C:\Users\Mikey\Desktop\pet\reservation-frontend.
Стек: React, TypeScript, Vite, обычный CSS. Один экран, без авторизации.
Ресурсы с постраничным просмотром и созданием; выбор ресурса; поиск свободных интервалов на выбранный день; создание брони; список броней за день и подтверждение отмены.
Время ввода/вывода локальное для браузера, передача UTC. Сервер отвечает за транзакционную проверку. Повтор POST автоматически не выполняется. При 409 обновляем данные. При ошибке чтения прежние данные скрываем.
Vite проксирует /api к 127.0.0.1:8080; пароль БД во frontend не передаётся.
Шаги: конфигурация и тесты → интерфейс и API → проверка типов/сборки → браузерные сценарии → инструкция.
Проверки: создание/отмена, конфликт и обновление доступности, неверный интервал, недоступный backend, реальные запросы к PostgreSQL через Java API.
